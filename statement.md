# Mess Menu Manager

## Problem Statement

In a college mess, students often have to ask the mess staff about what food will be served on a particular day. It can also be difficult for the mess incharge to manage changes in the weekly menu.

This project is made to provide a simple way to manage and check the mess menu using Python.

## Scope

The project has two sections: Student and Mess Incharge.

Students can select any day of the week and check the complete menu for that day. The mess incharge can add, edit, delete and view the menus.

Each day has four meal timings:

- Breakfast
- Lunch
- Snacks
- Dinner

## Objectives

- To make it easier for students to check the mess menu.
- To provide a simple way for the mess incharge to manage menus.
- To save the menu so that it can be used again.
- To practice Python programming and file handling.

## Target Users

- College students
- Mess incharge

## Main Features

- Student menu viewing
- Add a menu for a day
- Edit an existing menu
- Delete a menu
- View all available menus
- Save menu information in a text file
