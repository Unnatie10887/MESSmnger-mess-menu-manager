# Mess Menu Manager

This is a simple Python project for managing the college mess menu.

I made this project so that students can check what food is available in the mess on any particular day. There is also a separate section for the mess incharge where the menu can be added or changed.

## What the project can do

There are two sections in the program:

### Student

Students can:

- Check the menu for any day
- Check breakfast menu
- Check lunch menu
- Check snacks menu
- Check dinner menu

### Mess Incharge

The mess incharge can:

- Add menu for the day
- Edit a menu
- Delete menu
- View all the menus

The menu is divided into four parts:

- Breakfast
- Lunch
- Snacks
- Dinner

## How to run

1. Install Python 3.
2. Open the Mess-Menu-Manager folder.
3. Open the terminal in the project folder.
4. Run: `python main.py`
5. Select Student or Mess Incharge.
6. Follow the options shown on the screen.
7. if error occurs then type cd "MESSmnger-mess-menu-manager-main" in terminal.
8. then type python main.py
